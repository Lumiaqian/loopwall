# EmptyState

空状态：在列表还没有内容时，说清是什么、下一步怎么做。

源码：`widgets.go` 的 `emptyState`。

**调用方提供**：一个图标、一句短标题（「还没有视频」「正在查找附近的 Mac…」）、一两句说明，以及可选的操作入口函数（`action ...func()`，如空资料库的「导入视频」、空播放列表的「前往资料库」、本地网络权限被拒时的「打开本地网络设置」）。需要系统权限时提前说明会弹什么、该怎么选。

**规格**：64px 图标底、圆角 18px、`accent` 12% 着色、图标 28px `accent`；标题 `empty-title`，说明 `detail` / `text-muted`；内边距 `space-40`，间距 `space-10`，居中。
