# 使用说明

应用安装在 `~/Applications/Loopwall.app`，源码仓库为 [Lumiaqian/loopwall](https://github.com/Lumiaqian/loopwall)，本机检出在 `~/tools/phosphene-go`，主分支为 `main`。

## 常用操作

- 资料库：批量导入（「导入视频」按钮，或把视频、文件夹直接拖进窗口；文件夹会递归导入其中的 MP4、MOV、M4V，跳过隐藏文件）、预览、读取媒体信息、重命名、加入/移出轮播、删除副本。
- 播放列表与显示器：上移/下移顺序、统一设置播完切换或指定秒数、查看各屏位置；每块屏可单独固定循环资料库中的某个视频（显示器卡片的「播放」菜单，或资料库卡片「⋯」→「设为壁纸」），其余屏继续轮播。
- 设置：接电锁屏亮屏、登录启动、局域网共享、打开系统墙纸设置和资料库目录。
- 局域网共享：在一台 Mac 的「设置 → 局域网共享」打开「共享我的资料库」，那里会显示 6 位配对码；在另一台 Mac 的「附近的 Mac」页面找到它，输入配对码配对后即可浏览并导入其视频。导入是原画质复制到本机资料库并加入轮播，之后与对方无关；对方关机或关闭共享不影响已导入的视频。共享方需要开着管理端（菜单栏常驻即可）。第一次查找时 macOS 会询问本地网络权限，共享方首次可能弹出防火墙的传入连接提示，都需允许。
- 关闭主窗口：管理端保留菜单栏。菜单栏“打开资料库”可重开。
- 完全退出：菜单栏选择“退出管理端（壁纸继续播放）”。扩展仍由系统宿主管理。

视频以原始画质复制，不重新编码。删除仅针对新应用的副本，源文件保留。空列表不会主动清黑已经在显示的桌面。
