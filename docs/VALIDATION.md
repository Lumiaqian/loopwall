# 真机验证状态

自动测试（`scripts/test.sh`、`go test -race ./...`、`design_test.go`）覆盖逻辑；这里只记录**真实画面和硬件行为**的验证情况。播放进度或日志不代替真实画面。环境：macOS 27.0.1、Apple Silicon，内建屏加一台 U2790B 外接屏。最近更新：2026-11-14。

## 已在真机确认

- 两屏 4K 持续播放，播完切换与按时长切换都正常，切换没有明显黑屏；管理端完全退出后壁纸继续播放。
- 按显示器固定单个视频：固定的屏只循环该视频，另一屏照常轮播，取消固定后从当前视频接着轮播（通过改配置并通知扩展验证）。
- 墙纸服务卡住时，安装脚本与「修复壁纸」重启 WallpaperAgent 后恢复播放；扩展注册丢失时安装脚本会重新注册。
- 从 Phosphene Go 改名迁移：13 个视频、播放列表与设置完整搬到 Loopwall 的新容器，内容逐项一致。
- 局域网共享的单机链路：真实 Bonjour 发布、发现、解析后，经 TLS 配对并完整下载，数据逐字节一致。
- 液态玻璃界面三档外观、侧栏玻璃导航、滚动边缘在真机截图中确认。
